# Sound clips (optional)

The MEME SOUNDBOARD works with zero audio files because every pad has a
Web Audio API synthesized fallback that fires instantly.

To use real clips, add MP3 files with these exact names:

- `daya-darwaza.mp3` — ACP Pradyuman "Daya, darwaza tod do"
- `samay-samapt.mp3` — Amitabh "Samay samapt"
- `cid-theme.mp3` — CID suspense theme
- `cartoon-boing.mp3` — Cartoon boing

The soundboard checks for each file on mount and automatically prefers it over
the synthesized version. Keep clips short and royalty-free / owned by you.
