# Local HTML5 games

Drop self-contained HTML5 game folders or single-file games here.

Examples:

- `public/games/my-game/index.html` → served at `/games/my-game/index.html`
- `public/games/boing.html` → served at `/games/boing.html`

After adding a file, open **Owner → Admin**, create or edit a game and set its
**Hosted game URL** to the local path (for example `/games/my-game/index.html`).
Only upload games you own or have permission to distribute.
